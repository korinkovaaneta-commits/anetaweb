# Aneta o práci — pravidla práce na webu

Tyto instrukce platí pro celý projekt.

## Produkční web a pracovní postup

- Web osobní značky „Aneta o práci“ běží na `anetakorinkova.cz` a je nasazen přes GitHub Pages z repozitáře `korinkovaaneta-commits/anetaweb`.
- `main` je produkční větev. Její změny se mohou projevit na živém webu. **Bez výslovného souhlasu majitelky nikdy nepushuj do `main`.**
- Před každou změnou zkontroluj aktuální stav projektu, dotčené soubory a jejich souvislosti. Zachovej existující funkčnost i rozpracované změny.
- Měň pouze požadované části. Nepřidávej nevyžádané úpravy ani refaktoring.
- Zachovej responzivitu, cookies, GA4, privacy a ostatní produkční nastavení.
- Po každé změně proveď lokální kontrolu odpovídající jejímu rozsahu. U změn webu ověř dotčenou funkčnost i zobrazení na mobilu a desktopu.

## Značka a charakter webu

- Hlavní značka je **Aneta o práci**.
- Web není HR web ani web konzultantky. Je domovem osobní značky o tom, jak práce ovlivňuje život.
- Má působit moderně, minimalisticky, prémiově, lidsky, inteligentně, klidně a nadčasově.
- Inspirace: Linear, Notion, Stripe Press, Framer a Read.cv.
- Každá změna má podporovat značku „Aneta o práci“, dát vyniknout obsahu a nepůsobit korporátně, HR-ově ani jako klasická landing page.

## Vizuální pravidla

- Používej hodně whitespace a silnou typografii.
- Omez dekorace a barvy na minimum. Obsah je hlavní vizuální prvek.
- Primární barva je tmavě modrá, sekundární černá, akcent tlumená vínová/malinová.
- Nepoužívej gradienty, velké stíny, stock fotky, generické ilustrace, barevné proužky ani zbytečné ikony.
- Fotografie používej pouze vlastní, přirozené a spojené s tvorbou obsahu, prací nebo podcastem.
- Méně je více. Pokud lze něco odstranit bez ztráty významu, preferuj jednodušší řešení v rámci požadované úpravy.

## Obsah a jednotlivé sekce

- Články mají působit jako doporučené čtení moderního magazínu, ne jako blogový archiv.
- Podcast je výraznější vizuální pilíř webu.
- Newsletter „Dopis o práci“ má působit jako pozvánka ke komunitě.
- Sekce „O mně“ nemá být CV.
